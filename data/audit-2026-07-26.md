## Interprétation
- **OK** : le prix attendu apparaît quelque part sur la page → présomption de validité
- **ÉCART** : le prix attendu n'apparaît PAS sur la page (mais d'autres prix oui) → à vérifier manuellement, l'offre a peut-être changé de prix
- **URL_MORTE** : HTTP 4xx/5xx → URL cassée à corriger
- **PAGE_VIDE** : page chargée mais < 100 caractères visibles → probable protection bot ou JS bloqué
- **NON_VÉRIFIABLE** : prix 0 (inclus) ou `null` (rabais combo) → impossible à comparer automatiquement
- **ERREUR** : timeout / réseau / autre → réessayer manuellement
